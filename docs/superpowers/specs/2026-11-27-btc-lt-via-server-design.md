# Long-term on-chain — ดึงผ่านเซิร์ฟเวอร์ของเว็บ (design สั้น)

**วันที่:** 2026-11-27 · **ผู้ใช้สั่ง:** "แก้ไขให้ใช้งานได้ โดยยึดหลัก ใช้ของฟรี โหลดแบบไม่เสียเงิน แล้วให้ใช้ได้ตลอดไป"

## ปัญหาที่เจอ
prod (Vercel) โค้ดตรงกับ local ทุกไฟล์ แต่ภาพย้อนหลัง/ส่วนที่มาจาก Coin Metrics + Blockchain.com
ขึ้น "ไม่มีข้อมูล" เพราะเครือข่ายที่ผู้ใช้อยู่ **ตัดการเชื่อมต่อเว็บหมวดคริปโต** (CoinGecko · Binance · Coin Metrics · Blockchain.com
= ECONNRESET ที่ TLS · GitHub/Google/alternative.me/เว็บเราเอง = ปกติ · bitcoin-data.com ผ่าน TLS ได้) — localhost ยังขึ้นเพราะ
IndexedDB ของ origin นั้นมีข้อมูลที่ดึงสำเร็จไว้ก่อน ส่วน prod เป็นอีก origin ไม่มีของเก่า

## หลัก
ฟรีทั้งหมด (Vercel Hobby · แหล่งข้อมูลฟรีไม่มี key) · ไม่เพิ่มฟังก์ชัน (เต็ม 12) · ใช้ได้ทุกเครือข่ายที่เข้าเว็บเราได้ ·
ข้อมูลเดิมไม่หายเมื่อแหล่งล่ม · ไม่เผาโควตา BGeometrics ของ IP ผู้ใช้

## ที่จะทำ
1. **`/api/bitcoin?lt=history`** (โหมดใหม่ในฟังก์ชันเดิม): เซิร์ฟเวอร์ดึง Coin Metrics + Blockchain.com คำนวณ price · mvrv ·
   realizedPrice · mvrvZ (point-in-time) · puell ด้วยฟังก์ชันเดียวกับเบราว์เซอร์ (`public/btc-lt-history.js`) ปัดเลข 6 หลักนัยสำคัญ
   · CDN cache `s-maxage=21600, stale-while-revalidate=604800` (ล้มบางแหล่ง = 900 วินาที · ล้มทั้งคู่ = 502 no-store)
2. **เบราว์เซอร์ (btc-lt-history.js): เซิร์ฟเวอร์ก่อน** ต่อแหล่ง — ได้ครบใช้เลย · ไม่ได้ → ดึงตรงแบบเดิม · ล้มทั้งสองทาง = คงข้อมูลเดิม
3. **`/api/bitcoin?lt=bgeo&m=<key>`**: เซิร์ฟเวอร์ดึง BGeometrics รายตัวชี้วัด (CDN cache 1 วัน · stale 7 วัน = ทั้งเว็บดึงจริง
   วันละครั้งต่อตัว จาก IP ของ Vercel ไม่ใช่ IP ผู้ใช้) · ทำงานเฉพาะบน Vercel (`process.env.VERCEL`) — dev server ในเครื่องตอบ 503
   กันเผาโควตา IP ผู้ใช้ · 429/ล้ม = 503 no-store
4. **เบราว์เซอร์ (btc-onchain-live.js): ตรงก่อน (โควตาของผู้ใช้เอง) → ถูกตัด/โควตาหมด → ขอส่วนที่เหลือจากเซิร์ฟเวอร์** ·
   ได้ครบ = ไม่มีข้อความ error · เพดาน 10 คำขอต่อรอบไม่เกี่ยวกับทางเซิร์ฟเวอร์ · ทุกแถวยังผ่าน PLAUSIBLE
5. แหล่งข้อมูลบอก "ผ่านเซิร์ฟเวอร์ของเว็บ" เมื่อมาทางนั้น

## ไม่ทำ
บอทรายวันเขียน JSON ลง repo (ทำให้ push ของผู้ใช้ชน) · ฐานข้อมูลเพิ่ม · Smart DCA (ดึง Coin Metrics ตรงเหมือนกัน — แจ้งผู้ใช้แยก)
